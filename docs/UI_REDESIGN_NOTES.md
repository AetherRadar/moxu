# 墨序创作工作台改版

2026-09-20

## 使用入口

- `/library`：作品书库，支持新建、搜索、继续写作。
- `/project/:projectId/session`：创作工作台，保留原有项目路径。
- 新作品先引导创建第一章；人物设定与大纲是可选补充，不是开写前提。
- 章节与大纲分为两个页签；关系索引和高级章节工具默认收起。
- 新建章节进入正文；规划入口切到大纲页签。
- 助手按规划、写作、修改组织；示例仅填入输入框，不自动发送。
- 专注模式保留可见的退出按钮；窄屏侧栏改为可收起的浮层。

## 第二轮体验调整

- 使用暖纸色底、陶橙主操作、蜂蜜黄引导、雾蓝规划与助手、柔玫瑰起草入口；正文保留白纸与深色字。
- 章节树、创建弹窗、助手和规划工具显示“第一卷 / 第一章”。自定义卷名保留；内部章节 ID 与存储兼容。
- 新章只需可选标题和所属卷，自动编号；番外、插章收进“特殊章节”。创建成功后再切换文档，失败时保留表单输入。
- 创建后在正文中选择直接写、列提纲或请助手起草；引导按作品和章节记住选择。助手入口仅填入要求，不自动调用模型。
- 写作搭档顶部切换规划、写作、修改，显示当前章和参考资料状态；示例靠近输入框，提交按钮明确说明动作。
- 空白正文隐藏润色工具，空白章提纲隐藏正文重构工具；窄屏创建后收起覆盖正文的侧栏。

## 润色

仍默认使用 `moxu-polish:qwen3-1.7b` 和 Java 数字保护。用户选择正文后生成候选，预览差异并明确确认才应用。此轮没有更换模型、修改数字校验或更改存储格式。
